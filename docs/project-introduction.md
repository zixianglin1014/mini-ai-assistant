# Mini AI Assistant 项目介绍


## 项目背景

随着企业知识库、智能客服、AI Agent 等应用快速发展，
传统基于关键词匹配的信息检索方式难以满足复杂语义理解需求。

本项目设计并实现了一套基于大语言模型（LLM）的企业级智能 AI 助手系统，
通过 RAG 技术增强模型知识能力，
结合 Memory、Redis、Hybrid Search 等模块，
实现具备知识问答、多轮对话和上下文管理能力的智能应用。


---

# 项目目标

构建一个完整的 AI Application 系统：

用户输入问题

↓

FastAPI 服务

↓

业务处理层

↓

知识检索

↓

上下文增强

↓

LLM生成回答

↓

返回结果


实现从用户请求到模型输出的完整链路。


---

# 核心能力


## 1. 智能对话

基于大语言模型实现：

- 自然语言理解
- 多轮对话
- Prompt控制
- 参数配置


## 2. 企业知识库问答

通过 RAG Pipeline：

- 文档加载
- 文本切分
- Embedding
- 向量检索
- Rerank
- Context增强


实现基于私有知识库的精准问答。


## 3. 长短期记忆

支持：

- 用户历史消息保存
- Session管理
- Redis持久化


## 4. 企业级工程能力

包含：

- FastAPI服务化
- Docker部署
- Redis缓存
- 配置管理
- 自动化测试
